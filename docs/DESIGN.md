# Design direction

Reading this as: shared staff and admin login for an Indonesian church event team, in a warm editorial style, dial ENERGY 2 / RHYTHM 2 / MOTION 1.

- Audience: PKLU GPIB committee staff and admins using phones, tablets, and desktops.
- Job: enter a shared PIN before managing registration and check-in.
- Palette: warm paper, forest green, and one turmeric accent, as set by the implementation plan.
- Type: editorial serif for display text; readable sans serif for forms and controls.
- Motif: a perforated registration-slip seam. It connects the login screen to event registration without adding an invented logo or illustration.
- Motion: hover, focus, and form-state feedback only. Keep the login surface calm during event operations.
